### Android Signing Requirements
To enable Android builds, add these GitHub repository secrets:
- `KEYSTORE`: Base64-encoded keystore file
- `SIGNING_KEY_ALIAS`: Key alias (e.g., "swarlehtaire")
- `SIGNING_KEY_PASSWORD`: Key password
- `SIGNING_STORE_PASSWORD`: Keystore password

Generate keystore:
```bash
keytool -genkey -v -keystore swarlehtaire.keystore -alias swarlehtaire -keyalg RSA -keysize 2048 -validity 10000
base64 -i swarlehtaire.keystore | pbcopy  # Encode for GitHub secret
```
